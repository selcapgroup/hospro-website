# hospro-website — hospro.co.uk

- Root: the PUBLIC website (index.html, platform.html, modules/*.html, …, shared.css, images, CNAME).
- entity/: the PRIVATE JV prospectus at hospro.co.uk/entity (access code in entity/assets/site.v4.js). Not linked from the public site.

Upload rules: replace root files individually; for entity, delete the folder and upload the new entity FOLDER.
Never upload entity's contents into the root — that overwrites index.html (the public homepage).
Nothing from entity (pages/, assets/, img/, the PDF, README-UPLOAD.txt) belongs in the root.
